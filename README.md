# FlowPilot AI

**The AI-powered operating system for modern teams.**

A premium SaaS portfolio concept featuring a responsive marketing site and interactive product dashboard. The project deliberately uses realistic product data and interaction states so it can be presented as a polished design-and-engineering case study.

## Stack

React · Vite · TypeScript · Tailwind-inspired design tokens · Lucide · Recharts

## Run locally

```bash
npm install
npm run dev
```
